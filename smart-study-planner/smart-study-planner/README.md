# Smart Study Planner

A professional, responsive web-based study planner application built with HTML, CSS, JavaScript, and Bootstrap 5.

## Features

- **Dashboard**: Overview of study progress, upcoming tasks, and statistics.
- **Task Manager**: Add, edit, delete, and mark tasks as completed.
- **Subject Management**: Organize tasks by subjects.
- **Responsive Design**: Works seamlessly on desktop and mobile devices.
- **Interactive Charts**: Visual representation of study hours using Chart.js.

## Tech Stack

- **HTML5**
- **CSS3** (Custom styles + Bootstrap 5)
- **JavaScript** (ES6+)
- **Bootstrap 5** (UI Framework)
- **Chart.js** (Data Visualization)
- **FontAwesome** (Icons)
- **Google Fonts** (Typography)

## How to Run

1. Clone the repository or download the files.
2. Open `index.html` in your web browser.
3. Start planning your studies!
